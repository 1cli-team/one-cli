# Template cover generation

Mode: built-in image_gen (no CLI fallback).

Style reference: the existing public/examples/admin-starter/cover.png, supplied through its browser preview because local reference loading was unavailable.

Original six gallery covers are unchanged. The seven new PNGs are 1536 × 1024 and displayed in the existing 16:10 image containers.

## Shared prompt

Use case: stylized-concept. Asset type: One CLI website template gallery cover, landscape 1536x1024, safe for centered 16:10 crop. Create a NEW illustration matching the supplied reference image's established visual style, not a redesign or edit of that reference. Reference role: style only. Match warm ivory and pale peach backdrop, soft diffuse apricot glow, matte white rounded UI surfaces, subtle warm shadows, extremely restrained light gray interface lines and small orange accents. Polished minimal soft 3D product UI illustration, mostly frontal with very subtle perspective, same airy low-contrast premium feeling as the reference. Central subject fills about 75 percent of image width, generous margins, top-left corner clear for website category badge. No people, no watermarks, no framework logos, no large titles, no legible text except the explicit simple code symbols below; interface text represented by subtle gray strokes. This is a conceptual template cover, not a screenshot. The most recent image shows the reference cover in a browser; use only the artwork style, omit any black browser borders.
