This tutorial covers `one create`. See [templates](/en/tutorials/templates/) to choose projects, then continue with [environment variables](/en/tutorials/env-vars/).

## 1. Install the CLI

```bash
curl -fsSL https://1cli.dev/install.sh | bash
one --version
```

Manual options live in [installation](/en/docs/installation/).

## 2. Run `one create`

Pass a target directory to create an empty workspace, or omit it to enter the directory interactively:

```bash
one create my-workspace
```

Non-interactive form (for scripts and CI):

```bash
one create my-workspace --yes
```

Key flags:

| Flag | What it does |
|---|---|
| `--name <name>` | Workspace name (overrides positional arg's basename) |
| `--yes` | Skip all prompts; accept defaults |

For the full list, see the [`one create` reference](/en/docs/create/).

## 3. What got written

```bash
cd my-workspace
ls -la
```

You'll see something like:

```
.git/
.config/
AGENTS.md
apps/
mise.toml
one.manifest.toml
packages/
services/
```

Inspect the manifest:

```bash
cat one.manifest.toml
```

Key parts of the produced manifest:

- `version = 2` — TOML schema version
- `[workspace]` — workspace ID and display name
- `[env.infisical]` — optional binding and environment slugs; absent until configured
- `[projects.<name>]` — one table per project; absent in an empty workspace

## 4. Defaults wired by `one create`

Every new workspace gets two baseline capabilities without prompting:

| Capability | Implementation | What it gives you |
|---|---|---|
| `env` | Infisical | Direct process injection after binding; shell environment before binding |
| `dev` | mise | `one add` projects existing dev scripts into native mise tasks, run by [`one dev`](/en/tutorials/dev-local/) through mise |

CI is not configured by `one create` or `one add`, and no workflow file is generated automatically.

## 5. Add a project

Browse the [template guide](/en/docs/templates/), then add a project using its ID:

```bash
one add react-spa --name web --yes
```

Repeat `one add` for each project you need.

## 6. The first commit

```bash
git status
git add .
git commit -m "chore: scaffold workspace"
```

`one create` already ran `git init`. The first commit captures the skeleton.

## Common errors

| Code | Symptom | Fix |
|---|---|---|
| `INVALID_NAME` | Workspace name has unsupported characters | Use `^[a-zA-Z0-9][a-zA-Z0-9_-]*$` (kebab-case is safe) |
| `WORKSPACE_NESTED_FORBIDDEN` | Tried to `one create` inside an existing workspace | Run from a non-workspace directory |
| `EXISTING_TARGET_NOT_EMPTY` | The target directory already exists and is non-empty | Pick a different name, or empty the directory first |
| `TEMPLATE_NOT_FOUND` | one add refers to an unavailable template | Run [`one templates list`](/en/docs/templates-cmd/) or visit the [templates page](/en/tutorials/templates/) |

Full table: [error codes](/en/docs/error-codes/).
