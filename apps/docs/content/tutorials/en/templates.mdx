The [template catalog](/en/templates/) lists the 13 built-in One CLI templates. Filter by frontend apps, backend services, or shared libraries to compare their purpose and stack.

Each card keeps its image cover and shows the template name and description. Use the template ID with `one add`; you choose the project name separately.

## Choose by purpose

| Purpose | Template IDs |
| --- | --- |
| Backend API | `nestjs-api`, `go-api` |
| Web application | `nextjs-app`, `react-spa` |
| Content and documentation | `astro-site`, `starlight-docs` |
| Desktop and mobile applications | `electron-app`, `expo-mobile` |
| Shared code | `ts-library`, `go-lib` |
| Choose a stack later | `empty-app`, `empty-service`, `empty-library` |

Frontend apps go in `apps/`, backend services in `services/`, and shared libraries in `packages/`. Empty templates prepare the directory and project registration so you can configure a stack later.

## Create a workspace, then add projects

```bash
one create my-workspace --yes
cd my-workspace
one add react-spa --name web --yes
```

Repeat `one add` for other projects. Run it without a template ID to use the interactive picker. `one templates` also lists the catalog bundled with your installed CLI.
