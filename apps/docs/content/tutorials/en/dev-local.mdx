---
title: Local development
description: Select projects, customize mise tasks, and run development services.
---

Start the workspace with `one dev`, or select services explicitly:

```sh
one dev -p web -p api
one dev -p web --ui raw
one dev -p web -- --port 4300
one dev --dry-run -o json
```

One prepares tools and project dependencies, freezes each project's environment, and invokes mise once. mise runs upstream builds before the services that need them. Multiple services use prefixed logs; Ctrl+C stops the group. A failing task stops the invocation and returns its exit code.

Project commands come from package scripts, Taskfile, or the manifest's development command. Customize task dependencies and commands in `mise.toml`. One updates generated fields incrementally, preserving custom settings and comments. Custom mise commands use mise's environment; generated adapters inject One's project environment.

For arbitrary commands, use `one exec -p web -- pnpm add axios`. It runs in the selected project environment without invoking a task graph.

See [one dev](/en/docs/dev/) for terminal modes and dependency preparation, and [one run](/en/docs/run/) for task shorthand, overrides, and caching.
