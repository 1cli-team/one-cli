---
title: 配置环境变量
description: 登录 Infisical、绑定工作区，并在运行命令时注入变量。
---

Infisical 保存变量值，`one.manifest.json` 记录绑定和变量名。One CLI 在执行命令时直接注入变量，无需中间 `.env` 文件。

## 1. 登录

```bash
one login
one whoami
```

浏览器会话保存在系统 keyring。新工作区可以先不绑定，正常创建和运行；需要托管变量时再登录。

## 2. 设置变量

在包含 `api` 项目的工作区中执行：

```bash
one env set DATABASE_URL -p api --env dev
```

终端会隐藏输入值。首次 env 操作在缺少绑定时初始化 Infisical 项目；如需使用已有项目，先在 Dashboard 工作区设置中选择该项目。

工作区根目录省略 `-p` 可操作共享变量，交互式 `set` 提供作用域选择。脚本显式传入值，并使用 `--yes` 确认变更。

## 3. 查看变量名

```bash
one env list -p api --env dev
one env get DATABASE_URL -p api --env dev --reveal
```

`list` 只显示名称。确实需要查看值时才使用 `--reveal`。

## 4. 运行项目

```bash
one exec -p api --env dev -- go run ./cmd/server
one run dev --env dev
```

绑定启用 Infisical 注入，未绑定项目继承 shell 环境。已绑定项目认证或拉取失败会停止执行，不使用本地文件回退。
