[模板目录](/zh/templates/)展示 One CLI 当前内置的 13 个模板。可以按前端应用、后端服务和共享库筛选，查看各模板的用途和技术栈。

每张卡片保留图片封面，并展示模板名称和简介。模板 ID 用于 `one add`，项目名称由你决定。

## 根据用途选择

| 用途 | 模板 ID |
| --- | --- |
| 后端 API | `nestjs-api`、`go-api` |
| Web 应用 | `nextjs-app`、`react-spa` |
| 内容站与文档 | `astro-site`、`starlight-docs` |
| 桌面与移动应用 | `electron-app`、`expo-mobile` |
| 共享代码 | `ts-library`、`go-lib` |
| 暂时不选技术栈 | `empty-app`、`empty-service`、`empty-library` |

前端应用默认放在 `apps/`，后端服务放在 `services/`，共享库放在 `packages/`。空项目模板只准备目录和项目登记，技术栈可以之后再配置。

## 创建工作区，再添加项目

```bash
one create my-workspace --yes
cd my-workspace
one add react-spa --name web --yes
```

需要其他项目时继续使用 `one add`。不指定模板时，命令会提供交互选择；使用 `one templates` 也能在终端查看当前安装版本的完整目录。
