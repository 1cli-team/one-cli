```bash
one serve
one serve --port 0 --open=false
```

服务只允许回环地址。侧栏提供工作区、共享凭据和设置；所有页面共用当前 Infisical 账号。设置页打开浏览器登录，支持等待、重新打开、取消、退出和自定义实例。

共享凭据页支持一键初始化默认位置、新建项目或选择已有 Secret Manager 项目作为存放位置，按环境与目录浏览名称和说明。列表不包含明文；查看、复制、编辑和删除均显式操作。远端修改立即生效，删除会显示完整目标范围。

工作区概览展示项目构建命令和来源。工作区环境选择已有 Infisical 项目，项目配置与工作区绑定通过统一 Manifest 草稿审阅和保存；远端变量不进入草稿或仓库。浏览环境不会改变默认环境。

安全限制及 CLI 用法见[登录与本机设置](/zh/docs/login/)。

## 开发服务与控制台

通过终端运行 `one serve`，进入项目的「运行」页即可启动、停止或重启开发服务。启动沿用 `one dev` 的有效 dev 任务、工具与依赖准备，以及当前环境的 Infisical 变量注入。同一项目只能运行一个实例；不同项目可以分别启动。未保存的 Manifest 草稿需要先保存或丢弃。

控制台显示子进程原始日志；One 自己不打印注入的变量值。支持 ANSI 颜色、搜索、复制和暂停滚动，最多保留最近 256 KiB / 2,048 段输出。刷新页面会重新连接；关闭页面不会停止服务。交互式或 raw 任务仍需外部终端，控制台不接收命令输入。

页面会从日志中识别本机 HTTP(S) 地址。端口可连接后出现访问入口；这只表示端口可连接，不代表应用健康检查成功。无 Web 页面的后台服务也能运行。

环境选择只影响下次启动或重启，当前实例保留原来的环境。停止服务会清理其进程树；按 Ctrl-C 关闭 `one serve` 会停止它启动的全部服务。运行状态和日志只保存在内存中，重新启动 Dashboard 后不会恢复服务。
