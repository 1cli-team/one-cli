---
title: CLI overview
description: Daily commands and advanced entry points.
---

| Command | Purpose |
| --- | --- |
| `one create` | Create a workspace |
| `one add` | Add a project |
| `one dev` | Start development |
| `one build` | Build projects |
| `one env` | Manage project variables |
| `one login` / `one whoami` / `one logout` | Single browser session |
| `one env --global` | Discover global variable locations and environments |
| `one run` | Run a command with injected variables |
| `one serve` | Open the Dashboard |
| `one locale` | Local language preference |
| `one init mise` / `one init hooks` | Workspace tool configuration |
| `one ci` / `one templates` / `one skills` | Automation and resources |

Discover the full catalogue with `one help --all`, then read command-specific `--help`. Agents discover metadata and execution options through the CLI, without copying commands from the Dashboard. See [login and global variables](/en/docs/login/).
