## 编写文档

使用 Markdown 编写正文，使用 MDX 插入交互式 React 组件。

```tsx
import { Button } from "@/components/ui/button";

export function Example() {
  return <Button>开始使用</Button>;
}
```

查看[编写指南](/zh/docs/guide/)，了解内容组织和发布方式。
