## Your first page

Edit `content/docs/en/index.mdx` to introduce your product. Create a matching page
under `content/docs/zh/` for Chinese readers.

## Write documentation

Use Markdown for content and MDX for interactive React components.

```tsx
import { Button } from "@/components/ui/button";

export function Example() {
  return <Button>Get started</Button>;
}
```

See [the guide](/en/docs/guide/) for content organization and publishing.
