# one-template-go-api

Gin + Gorm + Viper + Zap API service generated by One CLI.

Requires Go 1.27 or newer. Use the latest patch release for your Go version.

## Commands

```bash
go mod tidy
task run
task check
task build
```

## API docs

Swagger UI is available at `http://localhost:8080/api/docs` when the
service is running. The UI reads the OpenAPI source at
`/api/openapi.yaml`; update `api/openapi.yaml` whenever routes or
response shapes change.

## Environment

Viper reads `configs/config.yaml` and process environment variables. Use `one env set <KEY>` to configure Infisical variables, then run project tasks through `one run` or commands through `one exec`.

使用 `one env set <KEY>` 配置 Infisical 变量，通过 `one run` 执行项目任务或通过 `one exec` 执行命令时自动注入。

```bash
DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/demo?sslmode=disable
JWT_SECRET=your-jwt-secret-here
CORS_ALLOWED_ORIGINS=http://localhost:3000,http://localhost:5173
```

## Layout

```text
cmd/server/            # executable entrypoint
internal/app/          # application wiring
internal/http/         # Gin routes, handlers, middleware, responses
internal/domain/       # domain models
internal/repository/   # Gorm repositories
internal/service/      # business services
internal/platform/     # infrastructure adapters
api/                   # OpenAPI spec
configs/               # config examples
migrations/            # database SQL migrations
scripts/               # operational scripts
Taskfile.yml           # go-task tasks
```
