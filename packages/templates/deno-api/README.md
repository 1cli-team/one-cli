# one-template-deno-api

Deno HTTP service in a pnpm workspace. One prepares dependencies and runs the package scripts.

pnpm 工作区中的 Deno HTTP 服务。One 准备依赖并执行 package.json 中的任务。

```sh
one run check -p one-template-deno-api
one run build -p one-template-deno-api
```

Set `PORT` through One to choose the listening port (default 3000).

通过 One 设置 `PORT` 可选择监听端口，默认 3000。
