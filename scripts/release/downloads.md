## 安装包 / Downloads

CLI 与 Desktop 来自同一版本、同一源码提交。CLI 使用 checksums.txt 校验；桌面安装包使用 desktop-checksums.txt。macOS 应用及 DMG 已签名、公证并附加票据；Windows/Linux 桌面包未签名。桌面版应用内自动更新尚未启用，请下载新版安装包更新。

CLI and Desktop share this version and source commit. Verify CLI archives with checksums.txt and desktop installers with desktop-checksums.txt. macOS apps and DMGs are signed, notarized and stapled; Windows/Linux desktop installers are unsigned. Desktop in-app updates are not enabled; install the newer package to update.
